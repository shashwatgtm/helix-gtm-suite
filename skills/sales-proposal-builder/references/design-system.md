# Helix GTM Design System Reference

- Typography: System Sans / Inter (Headings), IBM Plex Mono (Metrics & Tables)
- Primary Palette: Deep Navy (#0F172A), Slate (#334155), Signal Amber (#D97706), Emerald (#059669)
- House Rules: Zero em/en dashes, British English spelling, mandatory `[User to add: ...]` placeholders for unverified customer numbers.
